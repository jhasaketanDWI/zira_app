Environment Setup Steps (Django Project)

Install django-environ package.

Create a .env file in the project root directory (same level as manage.py).

Add all required environment variables inside the .env file (SECRET_KEY, DEBUG, DB credentials, Email, Google OAuth, Cashfree, etc.).

Add .env to .gitignore.

Install MySQL and create the database.

Install MySQL driver (mysqlclient).

Configure Gmail App Password for SMTP.

Create Google OAuth credentials in Google Cloud Console.

Run makemigrations.

Run migrate.

Start the Django server using runserver.
